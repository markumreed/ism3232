Python runner — cold start

Press Run ▶: expect starting Python…, then 4. A second Run is instant.

print(2 + 2)
First Run triggers the Pyodide cold boot (~10 MB from the jsDelivr CDN). The button shows "starting Python…" then prints 4. Re-running is instant because the runtime is cached.

Python runner — stdin

A stdin box appears because the code calls input(). Type two lines, Run — prompts and values echo. Empty the box and Run — expect an EOFError traceback.

first = input("First name: ") last = input("Last name: ") print("Hello,", first, last)
Two input() calls. Feeding "Ada" then "Lovelace" echoes "First name: Ada", "Last name: Lovelace", then "Hello, Ada Lovelace". Clearing the stdin box makes input() raise EOFError — a real Python traceback, not a JS error.

zsh terminal — seeded filesystem

pwd → /Users/student/demo  ·  ls → a.txt  ·  cat a.txt → hello  ·  unknown command → zsh: command not found  ·  Run all replays the seeded lines.

cd demo pwd ls cat a.txt
The data-fs attribute seeds ~/demo/a.txt. The shell starts at $HOME (/Users/student), so the first seeded line is "cd demo". Type an unknown command such as "frobnicate" to see the not-found error. Run all replays cd demo / pwd / ls / cat a.txt.
