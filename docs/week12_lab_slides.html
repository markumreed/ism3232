The instructor's worked example — event registrations (a model of the process)

Concept

Business Domain. A system for managing registrations to a company's annual gala event — tracking who's signed up, at what price tier, and whether they're confirmed, pending, or cancelled.

Entity Class 1 — Registration. Attributes: reg_id: int, attendee_name: str, event: Event (a reference to Entity Class 2), price: float, status: str (defaults to 'Pending'). Methods: confirm() → None, cancel() → None, is_vip() → bool (True if price exceeds $500).

Entity Class 2 — Event. Attributes: event_id: int, name: str, capacity: int. No methods required beyond __init__ and __repr__ for this domain.

Manager — RegistrationManager. Holds a list of Registration. Methods: add(registration), list_by_status(status), total() (sums price), report() (prints confirmed/pending counts and total revenue).

Business Rules. (1) A new registration starts as 'Pending' until confirmed. (2) A registration is VIP if its price exceeds $500. (3) Cancelled registrations still count in total revenue history but do not appear in the "Confirmed" report section.

Demonstrated live as a model of the design-to-code process, not as an answer to copy. Registration has-a Event — a genuine "many registrations, one event" relationship.

Entity Class 2 (Event) + Manager (RegistrationManager)

Concept

Event — a different kind of thing. event_id, name, capacity, plus __repr__. It doesn't reference Registration at all — the relationship runs the other way: each Registration holds a reference to its Event.

__init__(self): self.registrations = [] — composition in one line, exactly Week 11's shape: the manager has a list of Registration objects.

add(self, registration) — self.registrations.append(registration). Appends an already-built object; does not reassign the list.

list_by_status(self, status) — [r for r in self.registrations if r.status == status]. Genuinely parameterized — it uses the status argument, so different values return different results.

total(self) — sum(r.price for r in self.registrations), a generator-expression sum over a genuine numeric business attribute.

report(self) — a presentation method whose entire job is to print(); it calls self.list_by_status('Confirmed') and self.list_by_status('Pending'), reusing logic via self.

Line-by-line (guide, Part 3 worked example): - class Event: — __init__ sets event_id, name, capacity; __repr__ returns f'Event({self.event_id}, {self.name}, capacity={self.capacity})'. - RegistrationManager.__init__ — self.registrations = []. - add — appends; a reassignment here silently discards prior additions. - list_by_status — a Week-6-shaped comprehension over self.registrations, filtering on the status parameter, not a hardcoded string. - total — sum(r.price for r in self.registrations). - report — prints total count and ${self.total():,.2f}, then confirmed/pending counts, then each confirmed registration via __repr__. print() here is correct — it's a presentation method. Live-code — main.py: the full system end to end

class Event: """Represents a single event that people can register for.""" def __init__(self, event_id, name, capacity): self.event_id = event_id self.name = name self.capacity = capacity def __repr__(self): return f'Event({self.event_id}, {self.name}, capacity={self.capacity})' class Registration: """Represents one attendee's registration for an event.""" def __init__(self, reg_id, attendee_name, event, price): self.reg_id = reg_id self.attendee_name = attendee_name self.event = event self.price = price self.status = 'Pending' def confirm(self): """Mark this registration as confirmed.""" self.status = 'Confirmed' def cancel(self): """Mark this registration as cancelled.""" self.status = 'Cancelled' def is_vip(self): """Return True if this registration's price exceeds $500.""" return self.price > 500 def __repr__(self): return f'Registration({self.reg_id}, {self.attendee_name}, {self.event.name}, ${self.price}, {self.status})' class RegistrationManager: """Manages a collection of event registrations.""" def __init__(self): self.registrations = [] def add(self, registration): """Add a Registration to the collection.""" self.registrations.append(registration) def list_by_status(self, status): """Return registrations matching the given status.""" return [r for r in self.registrations if r.status == status] def total(self): """Return the total revenue across all registrations.""" return sum(r.price for r in self.registrations) def report(self): """Print a formatted summary of all registrations.""" confirmed = self.list_by_status('Confirmed') pending = self.list_by_status('Pending') print(f'Total registrations: {len(self.registrations)} | Revenue: ${self.total():,.2f}') print(f'Confirmed: {len(confirmed)} | Pending: {len(pending)}') print('Confirmed registrations:') for r in confirmed: print(f' {r}') # Live-code — the library-checkout domain, same shape

class Book: """A book that can be borrowed from the library.""" def __init__(self, book_id, title, author): self.book_id = book_id self.title = title self.author = author def __repr__(self): return f'Book({self.book_id}, {self.title})' class Loan: """One borrower's loan of one book.""" def __init__(self, loan_id, borrower, book, days_out): self.loan_id = loan_id self.borrower = borrower self.book = book self.days_out = days_out self.status = 'Open' def return_book(self): """Mark this loan as returned.""" self.status = 'Returned' def is_overdue(self): """Return True if the book has been out more than 14 days.""" return self.days_out > 14 def __repr__(self): return f'Loan({self.loan_id}, {self.borrower}, {self.book.title}, {self.status})' class LoanManager: """Manages a collection of library loans.""" def __init__(self): self.loans = [] def add(self, loan): """Add a Loan to the collection.""" self.loans.append(loan) def list_by_status(self, status): """Return loans matching the given status.""" return [loan for loan in self.loans if loan.status == status] def overdue_count(self): """Return how many loans are currently overdue.""" return sum(1 for loan in self.loans if loan.is_overdue()) dune = Book(1, 'Dune', 'Herbert') mgr = LoanManager() mgr.add(Loan(1, 'Sam', dune, 20)) mgr.add(Loan(2, 'Alex', dune, 7)) print(mgr.loans[0].is_overdue()) print(mgr.loans[1].is_overdue()) print(mgr.overdue_count()) mgr.loans[0].return_book() print(len(mgr.list_by_status('Open')))
