Step 1 — Confirm zsh and Find Your Config File
🖥
Locate ~/.zshrc
Mac + Windows (WSL)

Same file, same path, on both platforms — the only difference is which terminal window you're typing into.

1
Confirm you're running zsh

Mac: use Terminal or the VS Code integrated terminal. Windows: open your Ubuntu/WSL terminal, not PowerShell.

echo $SHELL

Expected: /bin/zsh (Mac) or /usr/bin/zsh (WSL). If you see something else, revisit Tool 5 in the Pre-Course Setup Tutorial before continuing.

2
The file itself

~/.zshrc is a hidden configuration file in your home directory. zsh reads it every time a new terminal opens. Anything defined inside — aliases, functions, environment variables — is instantly available in every terminal session on that machine.

Step 2 — Back Up What's Already There
⚠
Do not delete an existing .zshrc
Homebrew, your OS, or a previous tool install may have already added lines to this file. The same safety habit you use with rm applies here: look before you touch it.
1
Check if the file already exists
ls -la ~ | grep .zshrc

If it's there, back it up before changing anything:

cp ~/.zshrc ~/.zshrc.backup

If ls shows nothing, that's fine — you'll create a fresh file in the next step, and there's nothing to back up.

Step 3 — Open the File in VS Code
1
Open ~/.zshrc
code ~/.zshrc

This opens (or creates) the file in your editor. If it already has content, do not delete it. Scroll to the bottom — that's where your block goes.

Step 4 — Paste the Required Block
1
Add these lines to the bottom of ~/.zshrc

Read every line before you paste it — you'll need to explain each one.

~/.zshrc — required block
# ISM3232 required aliases
alias ll='ls -la'
alias c='clear'
alias py='python3'
alias gs='git status'
alias ga='git add .'
alias gcmsg='git commit -m'
alias gp='git push'
alias gl='git log --oneline'
alias tree2='tree -L 2'

# Required shell function
mkcd() { mkdir -p "$1" && cd "$1" }
💡
Optional bonus — Week 4 power tools
The lines below are not required for grading — they're the zoxide / fzf material from Week 4. They're written to do nothing if you haven't installed those tools yet, so it's safe to paste this block even before that week.
~/.zshrc — optional (Week 4 power navigation)
# zoxide: smarter `cd` — after visiting a folder a few times,
# `z partial-name` jumps there from anywhere
if command -v zoxide >/dev/null 2>&1; then
  eval "$(zoxide init zsh)"
fi

# fzf: fuzzy search — Ctrl+R fuzzy-searches your command history
if command -v fzf >/dev/null 2>&1; then
  source <(fzf --zsh) 2>/dev/null
fi
Save the file when you're done

Whether you pasted just the required block or the bonus one too, save ~/.zshrc now (⌘S / Ctrl+S) before moving to Step 5.

Step 5 — Apply the Changes and Verify Every Alias
1
Reload the file into your current terminal

Editing .zshrc doesn't affect a terminal that's already open.

source ~/.zshrc

No output means it worked. Every new terminal window loads it automatically from now on — you only need source again after you edit the file.

🏁
Run each of these and confirm the behavior
Don't assume it worked — test every piece, one at a time.
Verification sequence — run in the same terminal, in order
# 1. Detailed listing, including hidden files
ll
Expected: shows .git, .venv, .gitignore, etc. alongside your normal files

# 2. Git status shortcut
gs
Expected: "On branch main..." (or similar) if you're inside a git repo

# 3. Python shortcut
py --version
Expected: prints a Python 3.x version

# 4. Two-level directory tree
tree2
Expected: shows your folders, 2 levels deep

# 5. Make-and-enter-directory function
mkcd testdir
pwd
Expected: testdir/ was created AND you are now inside it

# 6. Clean up the test folder (safety ritual: pwd, ls, then rm)
cd ..
pwd
ls
rm -r testdir
Expected: testdir is gone; ls no longer lists it

Troubleshooting — Common Problems and Fixes
⚠ Problem
zsh: command not found: gs
✓ Fix
You edited the file but never reloaded it. Run source ~/.zshrc in that terminal, or just open a new terminal tab.
⚠ Problem
Your old ll still behaves differently than expected
✓ Fix
Something later in .zshrc (an Oh My Zsh plugin, for example) redefines it after your block. zsh uses the last definition of a duplicate alias — move your ISM3232 lines to the very end of the file.
⚠ Problem
mkcd: command not found
✓ Fix
The function block didn't get pasted, or has a typo. Reopen code ~/.zshrc, confirm the mkcd() { ... } block matches exactly, then source ~/.zshrc again.
⚠ Problem
Pasted the block but nothing changed
✓ Fix
Confirm you edited ~/.zshrc and not ~/.zshrc.backup by mistake — run code ~/.zshrc again and check the tab name.
⚠ Problem
tree2: command not found
✓ Fix
That's a missing tool, not a config problem — tree itself isn't installed. Run brew install tree (Mac) or sudo apt install tree -y (WSL), from the Pre-Course Setup Tutorial.
⚠ Problem
permission denied opening ~/.zshrc
✓ Fix
Rare — usually a home-directory permissions issue. Post on the course discussion board with the exact error before trying random fixes.
Getting Help

Post in the course discussion board with: (1) your operating system, (2) the exact command you ran, (3) the exact error message (screenshot preferred). Don't wait until the Week 3 lab to sort out a broken .zshrc — every ritual after this point assumes it's working.
